- **스폰 / 리스폰** `[le seu pon]`：英文 "respawn"，指遊戲裡的重生，即**人類重生點**。
- **ABC**：作為殭屍方，依序按下快捷鍵 `A`、`B`、`C`，代表**在監獄有人類**（同 `옥지원` 請求監獄支援）。
- **다리** `[da li]`：韓文的「橋」，指**監獄的上方**。
- **CBA**：作為殭屍方依序按下快捷鍵 `C`、`B`、`A`，指**重生點有人類**。
- **AC**：依序按下快捷鍵 `A`、`C`，指**來監獄上方**。
- **왼** `[win]`：左（副詞，加在動詞前）。
- **오른** `[o reun]`：右（副詞，加在動詞前）。
- **~쪽** `[jjog]`：方向（如 `왼쪽` = 左邊、`오른쪽` = 右邊）。
- **위** `[wi]`：上面。
- **아래** `[a rae]`：下面。
- **정면** `[jeong myeon]`：中文的「正面」。因為在一般點位有兩個面容易混淆，基本上**只用於監獄**（監獄只有一個面朝外，可理解為上＋下）。
- **중간** `[jung gan]`：中間，指場地中央。
- **통로** `[tong lo]`：通路，指地圖中的某些特定通道。
- **근처** `[geun cheo]`：近處，指附近。
- **주변** `[ju byeon]`：周邊，指附近（範圍比 `근처` 更廣）。

【《殭屍學園》[越獄溝通與對話用語（整理：Tio / 翻譯：條碼 / 補充：白貓）]】
- **나** `[na]`：我（搭配點位＋方位使用）。
- **인간** `[in gan]`：古韓文漢字「仁間」，指**人類**。
- **~명** `[myeong]`：中文的「~名」，人數單位（例如：`2명` = 有 2 個人類）。
- **ㅇㄷ / 어디 / 어디에요** `[eo di e yo]`：哪裡。
  * 例：`인간 어디?`（人類在哪裡？當你是殭屍、人類剩一人時詢問剩餘人類在哪，回答通常以 A / B / C 回答靠近哪一區）。
- **가는중 / 가는종** `[ga neun jong]`：正在走，即「正在路上 / 前往」。
- **~피** `[~pi]`：~滴血（例如：`1피` 指殭屍只剩 1 滴血）。
- **몇** `[myeoch]`：詢問數量的詞「幾 / 多少」（問有多少人或殭屍）。
- **옥 몇** `[og myeoch]`：詢問**監獄有幾隻殭屍防守**。
- **A / B / C 몇**：詢問**在 A / B / C 區有幾隻殭屍**。
- **ㄴㄱ (누구)** `[nu gu]`：誰，通常用於確認隊友位置（例如：`옥 ㄴㄱ?` = 監獄誰在防守？）。
- **어글 (어그리다)** `[eo gei ri da]`：引誘（拉仇恨）。
- **선 비 (선 B)** `[seon bi]`：中英文組合「先 B」，指**先打 B 機關**（特定地圖用）。
- **지원** `[ji won]`：中文的「支援」。

【《殭屍學園》[越獄裝置（開關/機關）攻防用語（整理：Tio / 翻譯：條碼 / 補充：白貓）]】
- **스치 / 스위치** `[seu wi chi]`：英文 "switch"（開關），指越獄裡的**機關**。
- **몸막 / 몸빵 / 스위치 몸빵** `[seu wi chi mom bbang]`：`몸` 指身體，`빵` 指撞擊（`몸빵` 在遊戲中指坦住）；全詞指越獄中，**守方殭屍以身體阻擋（撞擊）攻擊方的弓箭，來阻止人類攻擊機關的基礎技巧**。
- **선몸빵** `[seon mom bbang]`：`선` 為「先」，指在攻擊方開始打機關前，**就先用身體擋住機關**的行為。
- **뚫노매 (뚫리면 노란 매크로)** `[ddulh no me no lan mae keu lo]`：`뚫리면` 指被穿透/突破時，`노란` 為黃色；指**將自己要打（或已突破）的機關，以黃色顏色的快捷訊息通知隊友**。
- **늦스위치** `[neuj seu wi chi]`：一種**延後打開關**的戰略。
- **빈집** `[bin jib]`：韓文的「空屋」，指**沒有殭屍防守的開關（機關）**。
- **빈집털이** `[bin jib teol i]`：`털다` 為掏/偷竊，`빈집털이` 指偷空屋，即**偷打沒有殭屍防守的機關**。

- **선옥** `[seon og]`：指遊戲開始時**就開始守監獄、不守開關**的戰術。
- **양옥 (양쪽 옥헬)** `[yang jjog og hel]`：雙向監獄救人，指**監獄分頭救人**。
- **ㅌㅇ (투옥)** `[tu og]`：英文中文組合 "two 獄"，指**有 2 隻殭屍在守監獄**。
- **ㅌㅇㅈ (투옥하는 중)** `[tu og ha neun jung]`：正在 `투옥`，指**自己正在進行 2 人防守監獄**。

【《殭屍學園》[越獄走位與控制技巧（컨트롤）（整理：Tio / 翻譯：條碼 / 補充：白貓）]】
- **관통** `[gwan tong]`：中文的「貫通」，指**利用殭屍被弓射中時會變得無法造成傷害（貫通狀態）時，穿透殭屍的技巧**。
- **0칸** `[0 kan]`：指越獄裡，**將機關附近的殭屍打成貫通狀態，再 0 距離（0 格）打機關**的一種技巧。
- **번개** `[beon gae]`：韓文中的「閃電」，指在越獄裡用 `ㄱ`、`ㄴ`、`Z` 等路線近距離打殭屍與機關的一種近戰走位技巧。
- **~자** `[~ja]`：指 `~字形` 繞法形狀：`ㄱ자`（倒 L 字形）、`ㄴ자`（L 字形）、`Z자`（Z 字形）。
- **돌아돌아 컨 (돌아돌아 컨트롤)** `[dol a dol a keon teu lol]`：`돌아돌아` 指不停往返，指一種**在機關四周不停往返打機關**的技巧。
- **물방 / 물방 컨 (물레방아 컨트롤)** `[mul le bang a keon teu lol]`：`물레방아` 為韓文中的「水車」，指在越獄中**像水車一樣轉動、控制對手殭屍的走位技巧**（在與殭屍同行時，往側邊變換走道，再從旁用弓擊中殭屍）。
- **다이빙 / 다이빙 컨 (다이빙 컨트롤)** `[da i bing keon teu lol]`：英文 "diving"（潛水），指**射出一箭假裝要穿過殭屍、再回頭**的一種走位技巧。
- **정지 컨 (정지 컨트롤)** `[jeong ji keon teu lol]`：`정지` 為終止/停，是一種當殭屍時的走位技巧：**在某些位置故意停下，讓原本預期射中殭屍進行貫通的人類玩家撞上殭屍**。
- **변칙 컨 (변칙 컨트롤)** `[byeon chig keon teu lol]`：`변칙` 為「變則（變化的）」，是一種**誘導對手以為自己要打機關的一邊、但其實是要打另一邊**的走位技巧。
- **따라 컨 (따라하는 컨트롤)** `[dda la ha neun keon teu lol]`：`따라` 為跟隨，指身為殭屍方，**在人類試圖貫通自己時，閃開攻擊並馬上跟上、抓住人類**的走位技巧。
- **일자 / 일자 컨 (일자 통로 컨트롤)** `[il ja tong lo keon teu lol]`：`일자 통로` 指某些地圖中一直線的單行道；`일자` 指**嘗試在單行道中殺掉殭屍的打法**（因為殭屍在單行道上無法閃避，被視為一種不禮貌的打法）。
- **일자충** `[il ja chung]`：指不會玩又經常使用 `일자컨` 的玩家（**貶義詞**）。
- **컨미 (컨트롤 미스)** `[keon teu lol mi seu]`：英文 "control miss"，指**操作失誤**。
- **백샷** `[bag syeos]`：英文 "back shot"，指越獄中**用弓箭射背後追著自己的殭屍**的基礎技巧。
- **근접 / 근거리** `[geun jeob / geun geo li]`：指當殭屍血量低時，**透過近距離攻擊來擊殺（捕捉）殭屍**的技巧（通常使用 `근접`）。
- **샌드 (샌드위치)** `[sae deu wi chi]`：英文 "sandwich"（三明治），指在越獄中，**多隻殭屍一起包夾正在打裝置的人類**的基本技巧。

【《殭屍學園》[越獄與天梯其他用語、Lag 判定與貶義詞（整理：Tio / 翻譯：條碼 / 補充：白貓）]】
- **래더** `[lae deo]`：英文 "ladder"，指**天梯或排位**。
- **매크로** `[mae keu lo]`：英文 "macro"（巨集），指**快捷訊息**。
- **라승 (라운드 승리)** `[la un deu seung li]`：英文中文組合 "round 勝利"，指不是透過破壞裝置，而是**透過分數（回合時間到）勝利**。
- **숨플 (숨어서 플레이)** `[sum eo seo peul le i]`：指躲藏、玩捉迷藏。
- **중퇴 / 탈주 (중간 퇴장 / 탈출 주)** `[jung gan toe jang / tal chul ju]`：中退 / 脫局，即**中離**的意思。
- **기여** `[gi yeo]`：寄與（貢獻），指**透過打天梯提升部落分數**的行為。
- **좀킬 (좀비 킬)** `[jom bi kil]`：殭屍殺。
- **렉권** `[leg gueon]`：`렉` (lag) + `권` (權力/優勢) = **卡頓優勢**，指越獄中因為玩家很卡，對其他玩家造成損害而對自己形成優勢（**貶義詞**）。
- **메딕** `[mae dig]`（越獄專用貶義詞）：英文 "medic"（軍醫），與劇情模式意思不同；在越獄中，指**人類方常常自己失誤撞殭屍、專門給殭屍補血的人**（**貶義詞**）。
- **~ㄷ~ / ~대~** `[~dae~]`：`~對~` 的場面（例如：`1대1` = 1對1）。
- **칸잡 (칸 잡다)** `[kan jab da]`：在越獄中指**在跟殭屍距離一格以上時仍會被抓住的現象**。
- **대각 / 대각잡** `[dae gag jab]`：中文的「對角抓」，指**站在殭屍的對角卻被抓到**，是其中一種 `칸잡`。
- **렉잡 (렉 잡다)** `[leg jab da]`：因為 lag 的關係被抓到。
- **관렉 (관통 렉)** `[gwan tong leg]`：在貫通殭屍時因為 lag 導致被抓住。
- **벽박 (벽에 박았다)** `[byeog e bag ass da]`：插在牆上，指遊戲走位時沒走好撞到牆壁，即**卡牆**。
- **벽샷** `[byeog syas]`：指在越獄地圖中，在某些機關可以用的、**透過牆壁打機關的技巧**。
- **튀플 / 마라톤 (튀면서 플레이한다 / marathon)** `[twi myeon seo peul le i han da]`：指**遠離殭屍、確保安全的跑打玩法**；在天梯中（尤其 1 對 1 時）被當作不禮貌的玩法（**貶義詞**）。
- **튀플러** `[twi peul leo]`：專玩 `튀플` 的人（**貶義詞**）。
- **일피튀 / 1피튀 (일피 튀플)** `[il pi twi peul]`：指**殭屍只剩 1 滴血時，殭屍方玩 `튀플` 逃跑**，也被視為不禮貌的玩法（**貶義詞**）。
- **정렉 (일시적으로 정지되는 렉)** `[jeong leg]`：指遊戲 lag 時的**時間暫停**。
- **스틸** `[seu til]`：英文 "steal"，指**偷別人打到殘血的殭屍**（**貶義詞**）。
- **암나 / 암나무** `[am na mu]`：源自木排 `나무`，指**在排位戰裡搗蛋的人，特別是木排（沒有排位）的人**；有時也當作 `아무나` 的簡寫（**貶義詞**）。
- **암브 / 암브론 (암브론즈)** `[am beu lon jeu]`：與 `암나무` 同理，指**有青銅排但實力極弱的玩家**（**貶義詞**）。
- **용병** `[yong byeong]`：中文的「傭兵」，指**部落招來幫忙打排位的部落積分的人**，通常地位低於一般成員。
