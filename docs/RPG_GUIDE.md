# 🗡️ GeminiBot RPG 文字冒險與跑團專屬指南

本手冊專為喜歡文字冒險、TRPG 跑團、情侶雙人探險的玩家設計。
系統背後由 **本機 Python 程式 ＋ 本地 SQLite 權威資料庫 ＋ Gemini 思考推演引擎** 驅動，具備 **真隨機硬體擲骰、數值 100% 精準計算、永久不失憶、全隊存讀檔與拒絕學舌直接推進世界** 機制。

---

## 🚀 一、 3 秒極速開局

### 1. 單人冒險開局
在任何日常群聊頻道輸入：
`!rpg start 迷霧森林遺跡`
Bot 會自動在該頻道建立專屬獨立討論串（Thread），發布序幕與角色卡，直接在討論串說話即可出發！

### 2. 情侶雙人／多人成行開局 (Party Duo & Co-op)
1. 輸入 `!rpg start 幽暗地宮大冒險` 建立討論串（開局者會自動入隊）。
2. 其他隊友走進討論串，先輸入 **`!rpg join`**（或 `!party join`，亦可直接輸入 **`!sheet <角色設定>`** 帶卡參戰），再依需求設定：`!rpg name 莉莉亞`、`!rpg class 精靈法師`。
   *(註：必須主動入隊或匯入角色卡才會被列入隊伍，未入隊的旁觀者發言不會誤觸自動入隊！)*
3. 任何已入隊成員說一句：「我們點燃火把，推開地宮大門」，AI 就會切換為**小隊主持者 (DM)**，帶領整支隊伍冒險！
4. 想暫時退場或離隊時，隨時輸入 **`!rpg leave`**（或 `!party leave`）即可單獨退隊，不會影響其他隊友或清空手記！

## 🎮 二、 平常玩 vs 存讀檔 (Save & Load)

### 1. 平常玩：完全不需要打 `!load`（即時自動存檔）
* 本機資料庫具備 **即時自動存檔 (Auto-Save)** 機制。
* 只要討論串還在，你們隔了幾天隨時回到討論串說話，AI 都會自動讀取最新血量與裝備接續劇情，**不需要手動讀檔**！

### 2. 什麼時候需要用 `!save` 與 `!load`？
* **Boss 房門前防滅團（SL 大法）：**
  推開惡龍房門前輸入 `!save 惡龍門前`。如果擲骰大失敗被滅團，輸入 `!load 惡龍門前` 即可時光倒流、滿血滿裝重新來過！
* **通關開新篇章（跨討論串繼承）：**
  第一章通關後輸入 `!save 第一章通關`。未來在新的討論串開第二章時輸入 `!load 第一章通關`，全隊等級裝備直接跨時空繼承！
* **公頻隨便玩 ➔ 無痛搬家：**
  在日常公頻隨便開了局，不想洗版日常群聊時，在公頻打 `!save 暫存`，開專屬討論串打 `!load 暫存`，整套進度一秒搬家！
* **平行宇宙劇本切換：**
  可同時擁有 `!save 奇幻修仙` 與 `!save 賽博龐克`，隨時切換不同世界線。

## 👑 三、 全宇宙自適應角色卡 (Universal Character Sheet)

**系統完全不局限於 D&D！** 
底層設計為「世界觀自適應引擎 (World-Adaptive Engine)」，無論你們想玩的是：
* 🧘 **東方修仙 / 仙俠**：道號、宗門、靈根、修為境界、功法、本命法寶、儲物袋
* 🦾 **賽博龐克 (Cyberpunk)**：代號、街頭身分、義體植入 (時停/神經晶片)、黑客入侵、戰術風衣
* 🐙 **克蘇魯跑團 (CoC)**：調查員身分、理智值 (SAN)、意志/偵查/心理學、舊印護身符、神秘學
* 🏰 **歐美奇幻 / D&D**：種族、職業、陣營、六大核心屬性 (STR/DEX...)、防禦等級 AC
* 🏫 **都市異能 / 現代校園 / 戀愛輕小說**：代號/姓名、超能力等級、性格反差、隨身小物、秘密

無論你輸入什麼欄位（例如 `- **靈根**：雷天靈根` 或 `- **義體**：斯安威斯坦`），系統都能在 0.05 秒內自動辨識、存入專屬資料庫，並將這些特質永久釘在 AI 眼前！

### 1. 如何匯入角色卡？（兩種方式皆可）
* **方式 A：使用指令匯入 (`!sheet <文字或附檔>`)**
  直接打 `!sheet` 後面貼上你寫好的任何角色設定，或在 Discord 上傳角色卡文字檔（.txt / .md）打 `!sheet`，系統自動解析完成！
* **方式 B：自然對話貼上（AI 自動辨識調用）**
  在冒險討論串中，直接把角色卡發給 AI，Gemini 會自動調用工具寫入核心資料庫，並立刻以該世界觀專屬的口吻（如仙長道友、夜之城神機醫、克蘇魯守密人）熱情迎接你！

### 2. 查看角色卡 (`!sheet`)
隨時輸入 `!sheet`，Bot 會以無表格的乾淨 Embed 呈現你的角色，手機版閱讀絕不跑版！如果不是 D&D，系統**絕不會**硬塞六大屬性或 AC，而是只呈現屬於你該世界觀的「專屬特質、法寶道具與境界/身分」。

### 3. 各大世界觀角色卡範本（可自由修改欄位）：

## 👥 四、 雙人／多人組隊系統 (Party System)

* **主動入隊制（防路人誤入）：** 只有透過 `!rpg start`（開局者）、`!rpg join` / `!party join` 或匯入 `!sheet <角色設定>` 主動加入的玩家，才會進入 `!party` 名冊與 DM 敘事視野；未入隊者在討論串閒聊不會被硬塞進隊伍。
* **自由進退與不毀局：** 想離隊隨時輸入 `!rpg leave`（或 `!party leave`），會保留你的角色卡與裝備並讓其他隊友繼續推進；若有人忘記退隊就掛機，也可用 `!party kick @隊友` 將其暫時移出。
* **獨立數值與背包：** 隊伍中每位玩家擁有獨立的血量、職業與隨身道具，互不干擾。
* **隊伍看板 (`!party`)：** 隨時輸入 `!party`（或 `!team`），Bot 一次列出全隊成員的 HP 條、裝備與小隊當前目標。
* **AI 默契連攜描寫：** AI 會根據各成員職業主動描寫配合（例如聖騎士舉盾格擋、法師後排詠唱破敵）。
* **全隊一鍵打包：** 只要一人輸入 `!save`，已入隊成員與整趟手記會一併存檔；讀檔時也是全隊同時就位！

## 📓 五、 旅程獨立手記 (Journey Journal)

* **絕對不干擾生活記憶：** 冒險情報存於專屬手記表，絕不污染情侶日常生活記憶庫。
* **AI 自動記線索：** 探索中發現 NPC 弱點、密室機關、石碑文字時，AI 會自動調用工具寫入手記。
* **手動記錄 (`!note <內容>`)：** 玩家也可以隨時輸入 `!note 守衛老伯最怕老鼠` 記錄線索。
* **查閱手記本 (`!journal`)：** 隨時輸入 `!journal`（或 `!notes`）查看本趟旅程已累積的所有關鍵情報。手記會永遠釘在 AI 眼前，聊上百句都不會忘！

## 🎲 六、 TRPG 擲骰與判定檢定 (Dice & DC)

遇到關鍵、危險或具挑戰性的行動（撬鎖、攀爬、說服NPC、發動大招、躲避陷阱）時，由系統本機 D20 骰子判定勝負：

* **自定義擲骰指令：** `!roll`（預設 1d20）、`!roll 2d6`、`!roll 1d100`、`!roll 1d20+3`
* **DC 難度分級：**
  * 簡單 (DC 8)
  * 普通 (DC 12)
  * 困難 (DC 15)
  * 極難 (DC 18)
* **傳奇判定點數：**
  * 🌟 **擲出 20 點**：大成功 (Critical Success)！極度幸運的華麗神操作或巨大收穫！
  * 💀 **擲出 1 點**：大失敗 (Critical Fumble)！嚴重失手、引發突發危險或尷尬危機！
* **本機程式權威運算（避開 AI 數學與隨機數弱點）：**
  大語言模型（特別是 Flash-Lite 輕量模型）本質是文字預測，不擅長做四則運算與公正隨機數。在我們的系統中，**AI 完全不碰底層數字計算**！擲骰點數由 Python 原生 PRNG 隨機生成，血量增減與物品管理由 SQLite 資料庫運算，AI 只負責根據既定結果生動演出，保證 100% 精準與隨機。
* **拒絕學舌，直接推進世界 (Anti-Parroting Narrative)：**
  AI 主持人受到底層強規則約束：「嚴禁重複、總結或換句話說複述玩家剛剛說的話」，直接描寫世界環境變化、NPC 神態心理與新突發狀況，確保節奏緊湊不拖沓！

## 📖 七、 世界觀設定集 (Lorebook)

平常龐大的世界觀不佔用 Token，只有冒險中聊到關鍵字時，系統會在 0.001 秒內精準抽出來給 AI 參考：

* **整篇大文本批次匯入 (`!lore import`)：**
  支援附加 `.txt` 或 `.md` 設定檔案，或直接在指令後貼上一整篇設定。
  支援格式：`【名詞】說明...` 或 `名詞：說明...` 或 `1. 名詞 - 說明...`。
* **查看設定 (`!lore`)：** 查看目前已登錄的所有世界觀。
* **重置開新宇宙 (`!lore clear`)：** 一鍵清空舊世界觀，隨時匯入新設定。

## 📋 八、 RPG 模式專屬指令速查表 (Cheat Sheet)

### 冒險開局、組隊與角色卡
• `!rpg start [主題]`：自動建立專屬獨立討論串開局（開局者自動入隊）
• `!rpg join`（或 `!party join`）：主動加入當前頻道／討論串的冒險隊伍
• `!rpg leave`（或 `!party leave`）：單獨退出冒險隊伍（保留角色卡，不影響其他隊友）
• `!party kick <@隊友或角色名>`：將指定成員移出當前冒險隊伍
• `!sheet`：查看個人極詳細角色卡（含種族、陣營、六大屬性、AC、技能、背景人設）
• `!sheet <文字或附檔>`：批次匯入/更新極詳細角色卡並入隊（支援直接貼上或上傳 .txt/.md 檔案）
• `!rpg`：查看個人冒險狀態卡（血量條、裝備背包、地點、目標、手記數）
• `!party`：查看小隊全員名冊與血量（雙人/多人組隊面板）
• `!rpg name <角色名>`：更改個人角色名稱
• `!rpg class <職業名>`：更改個人職業稱號
• `!rpg reset`：重置當前頻道整個冒險並清空旅程手記開新局

### 存讀檔 (Save & Load)
• `!save <存檔名>`：保存當前進度與全隊快照（小隊角色＋手記一併打包）
• `!load <存檔名>`：在任何討論串或頻道載入存檔（小隊全員與手記一鍵還原）
• `!saves`：列出所有已保存的存檔清單與時間
• `!rpg delsave <存檔名>`：刪除指定存檔

### 旅程手記與情報
• `!note <線索>`：手動記錄冒險情報至手記本
• `!journal`（或 `!notes`）：查看本趟冒險的所有手記與關鍵線索
• `!rpg delnote <編號>`：刪除特定手記編號

### 擲骰與世界觀
• `!roll [表達式]`：TRPG 擲骰檢定（例如 `!roll`、`!roll 2d6`）
• `!lore`：查看所有世界觀設定清單
• `!lore import <文字或附檔>`：批次匯入整篇世界觀（支援 .txt/.md 檔案）
• `!lore add 關鍵字 | 內容`：新增單筆世界觀
• `!lore clear`：清空世界觀設定集
• `!lore del <編號>`：刪除特定設定編號
