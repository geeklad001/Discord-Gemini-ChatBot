# 🤖 Discord Gemini 全能社群助理與 TRPG 跑團機器人 (Community Edition)

這是一個專門為了 **Discord 社群群聊、日常陪伴、生活備忘與 TRPG 文字冒險跑團** 而設計的強大 AI 機器人！

內建生動自然的「隨性、微毒舌、冷幽默」常駐老油條群友人設，平時是靠譜又好聊的常駐夥伴（支援圖片、動圖與短影片分析），在大家想跑團時又能隨時化身專業且節奏明快的遊戲主持人 (Game Master)！

本專案專為**完全不會寫程式、沒有任何技術背景**的朋友打造。只需照著底下的教學點擊，約 10 分鐘就能讓自己的專屬 AI 機器人在 Discord 伺服器上線！

---

## 🌟 核心特色
- **💬 超自然日常聊天**：告別冷冰冰的客服罐頭訊息！像個真實群友一樣隨性閒聊、吐槽與陪伴。
- **🔓 自由暢聊無審查限制**：**預設全面解除 Google 安全審查過濾 (BLOCK_NONE)**，日常打鬧、開玩笑、心事傾訴或冒險打鬥時絕不輕易被攔截拒答！
- **🧠 專屬長期記憶庫 (`!memory`)**：記住每個人的喜好、習慣與重要約定，聊天時自動貼心提起。
- **📋 隨身待辦與定時提醒 (`!todo` / `!remind`)**：口語吩咐或指令記錄待辦、預約定時提醒，時間到了自動標註叫人。
- **🗡️ 完整 TRPG 冒險跑團引擎 (`!rpg`)**：支援獨立討論串開局、個人角色卡 (`!sheet`)、小隊面板 (`!party`)、真實命運擲骰 (`!roll`)、世界觀設定 (`!lore`) 與進度存讀檔 (`!save` / `!load`)。
- **🖼️ 全能視覺與貼圖識別（超強特色！）**：
  - **Discord 官方貼圖 (Stickers)**：不論是靜態還是動態貼圖，甚至只傳貼圖不打字，機器人都能看懂並給出有趣的反應！
  - **自訂表情符號 (Custom Emojis)**：群組特有的自訂表情、動態表情符號皆能自動抓取圖片識別。
  - **GIF 動圖與迷因 (Tenor / Giphy)**：從 Discord 內建 GIF 面板點選發送的動圖，會自動抽幀轉為多格畫面讓 AI 看懂動態劇情與迷因！
  - **圖片與影片**：支援一般圖片上傳，以及短影片附件與 YouTube / Shorts 影片連結分析。
- **🎨 人設個性自由改**：不用改任何程式碼，用「記事本」修改文字檔就能自由切換性格，並支援 `!reload` 免重開即時生效！
- **⚡ 超低門檻一鍵運行**：提供 Windows 專屬一鍵腳本，**不用開終端機輸入任何指令**！

## 🚀 零基礎超詳細安裝教學（跟著步驟點就對了！）

### 【第一步】申請 Discord 機器人（取得 Bot Token）

1. **進入 Discord 開發者中心**：
   - 使用瀏覽器打開 [Discord Developer Portal](https://discord.com/developers/applications) 並登入。
2. **建立機器人應用**：
   - 點擊右上角藍色按鈕 **「New Application」**。
   - 在 **NAME** 輸入你喜歡的機器人名字（例如：`阿吉` 或 `隨性群友`）。
   - 勾選同意服務條款，點擊右下角 **「Create」**。
3. **複製機器人身分證（Token）**：
   - 點擊左側選單的 **「Bot」**。
   - 找到中間的 **「Reset Token」** 按鈕點下去（若詢問點 Yes, do it!，若有雙重驗證請輸入驗證碼）。
   - 點擊 **「Copy」** 複製那一長串英數混雜的字串。
   > ⚠️ **【重要提醒】**：這串 Token 是機器人的專屬鑰匙，**千萬不要外洩給別人**！請先貼在記事本備用。
4. **🔥【極度重要！小白最容易漏掉的大魔王】開啟 Intents 權限**：
   - 在同一個「Bot」頁面往下滾動，找到 **Privileged Gateway Intents** 區塊。
   - **務必將以下三個開關全部點擊打開（變成藍色開關）**：
     - ✅ **Presence Intent**
     - ✅ **Server Members Intent**
     - ✅ **Message Content Intent**（🔥 沒開這個，機器人就無法看見群組訊息，會完全不理人！）
   - 打開後，點擊下方彈出的綠色按鈕 **「Save Changes」** 儲存！
5. **將機器人邀請進你的伺服器**：
   - 點擊左側選單的 **「OAuth2」** 裡面的 **「URL Generator」**。
   - 在 **SCOPES** 區塊中，只勾選：
     - ✅ `bot`
   - 下方會出現 **BOT PERMISSIONS** 區塊，請勾選以下權限：
     - ✅ Send Messages（發送訊息）
     - ✅ Send Messages in Threads（在討論串發送訊息）
     - ✅ Create Public Threads（建立公開討論串）
     - ✅ Embed Links（嵌入連結）
     - ✅ Attach Files（附加檔案）
     - ✅ Read Message History（讀取歷史訊息）
     - ✅ Add Reactions（新增反應）
   - 頁面最下方會產生一串 **GENERATED URL**，點擊右側的 **「Copy」**。
   - 在瀏覽器開新分頁貼上該網址，選擇你的 Discord 伺服器，點擊「授權」即可將機器人加進伺服器！

### 【第二步】取得免費 Google Gemini API Key

1. 打開瀏覽器前往 [Google AI Studio](https://aistudio.google.com/)。
2. 點擊登入你的 Google 帳號。
3. 進入後，點擊頁面上的 **「Get API key」** 按鈕。
4. 點擊 **「Create API key」**（若跳出選單，選擇 `Create key in new project` 即可）。
5. 複製產生的那一長串金鑰（開頭通常是 `AIzaSy...`），貼在記事本備用。
   > 💡 Google 提供非常充裕的每日免費對話額度，個人使用完全免費！

---

### 【第三步】複製 Discord 聊天頻道 ID

我們要告訴機器人該在哪個頻道陪大家聊天：

1. 打開電腦版 Discord。
2. 點擊左下角自己頭像旁的 **「使用者設定」（齒輪圖示）**。
3. 往下拉到左側選單的 **「進階」**（英文版為 Advanced）。
4. 將 **「開發者模式」**（Developer Mode）開關打開（變為綠色）。
5. 關閉設定，回到你的伺服器。
6. 對著**你想讓機器人聊天的文字頻道**點擊滑鼠右鍵，點選最下方的 **「複製頻道 ID」**。
7. 這是一串純數字，複製並貼在記事本備用。

### 【第四步】安裝 Python 執行環境

機器人需要 Python 環境才能在你的電腦上跑起來：

1. 前往 Python 官方下載頁面：[Python 官方下載](https://www.python.org/downloads/)。
2. 點擊黃色按鈕 **「Download Python 3.12.x」** 下載安裝檔。
3. 雙擊執行下載下來的安裝程式。
4. 🔥 **【最致命陷阱！請看清楚】**：
   - 在安裝程式的第一個畫面，最下方有兩個勾選框：
     - [ ] Use admin privileges when installing py.exe
     - [ ] **Add python.exe to PATH** 👈 **務必！一定要把這個打勾！**
   - **請務必把 `Add python.exe to PATH` 打勾**，再點擊上方的 **「Install Now」**！
   - 安裝完成後點擊「Close」關閉。

### 【第五步】下載專案與一鍵啟動（點 1、2、3 就好！）

1. **下載本專案**：
   - 在本 GitHub 頁面右上角，點擊綠色的 **`Code`** 按鈕，選擇 **「Download ZIP」**。
   - 下載後解壓縮到你喜歡的位置（例如電腦桌面）。
2. **依序雙擊三個小幫手**：
   - 🔹 **第 1 步：雙擊執行 `1_設定金鑰_Setup_Env.bat`**
     - 它會自動建立 `.env` 檔案並彈出「記事本」。
     - 請把剛才準備好的三串資料填入對應的位置（**等號後面不要留空格**）：
       ```env
       GEMINI_API_KEY=貼上你的Gemini_API_Key
       DISCORD_BOT_TOKEN=貼上你的Discord_Bot_Token
       TARGET_CHANNEL_ID=貼上你的純數字頻道ID
       ```
     - 按鍵盤 `Ctrl + S` 存檔，然後關閉記事本。
   - 🔹 **第 2 步：雙擊執行 `2_一鍵安裝_Install.bat`**
     - 黑色視窗會自動為你安裝需要的套件。
     - 請耐心等待 1~2 分鐘，看到「恭喜！所有環境與套件已安裝成功」後按任意鍵關閉。
   - 🔹 **第 3 步：雙擊執行 `3_一鍵啟動_Start_Bot.bat`**
     - 視窗會顯示正在啟動，最後顯示：
       ```
       🚀 [你的機器人名字] 已成功連線至 Discord！
       ```
     - 回到 Discord，你會看見機器人亮起綠燈上線了！
     - 在聊天頻道直接打字（例如：`今天好累喔`），它就會用語氣自然的風格回應你囉！
   > 💡 **小撇步**：保持黑色視窗開著，機器人就會一直在線上；想關閉機器人時，直接關閉該視窗即可。

## 📖 全功能指令手冊速查表

平時在頻道中**直接用自然口語說話即可**！例如說「記住我不吃牛肉」、「10分鐘後提醒我收衣服」、「幫我記待辦買牛奶」，AI 就會自動透過 Function Calling 幫你處理好。若想精準查詢或管理，可隨時使用以下指令：

### 📋 共同待辦事項 (!todo)
- `!todo`：查看所有未完成事項清單
- `!todo add <內容>`：新增待辦（例如：`!todo 買衛生紙`）
- `!todo done <編號/關鍵字>`：將事項標記為已完成（例如：`!todo done 1`）
- `!todo del <編號>`：刪除待辦事項
- `!todo all`：查看包含已完成的所有歷史紀錄

### ⏰ 定時提醒 (!remind)
- `!remind 10m 關火`：設定相對時間提醒（支援 `30s` 秒、`10m` 分鐘、`2h` 小時、`1d` 天）
- `!remind 18:30 倒垃圾`：設定今天或明天的指定時間提醒
- `!reminds`：查看目前所有尚未觸發的預約提醒
- `!remind del <編號>`：取消特定排程提醒

### 🧠 長期記憶庫 (!memory)
- `!memory`：查看目前所有已記錄的事實與喜好設定
- `!remember <事實>`：主動存入一筆長期記憶（例如：`!remember Ken 最喜歡喝拿鐵`）
- `!forget <編號>`：刪除特定編號的長期記憶

### 🎲 命運擲骰 (!roll)
- `!roll`：丟一顆標準 20 面骰 (D20 檢定)
- `!roll 2d6`：丟兩顆 6 面骰
- `!roll 1d20+5`：支援加減修正值的進階擲骰運算

### 🗡️ TRPG 跑團文字冒險 (!rpg / !sheet / !party)
- `!adventure [主題]`（或 `!rpg start [主題]`）：為冒險建立獨立的專屬討論串
- `!sheet`：查看個人詳細角色卡面板
- `!sheet [文字/檔名]`：匯入或更新角色卡
- `!party`：查看冒險小隊全員 HP 與狀態面板
- `!rpg`：查看當前個人冒險狀態小卡
- `!rpg name <名>` / `!rpg class <職業>`：快速修改名稱或職業

### 💾 冒險存讀檔與世界觀手記 (!save / !load / !lore)
- `!save <存檔名>`：為當前隊伍進度、血量與背包建立快照存檔
- `!load <存檔名>`：讀取並覆蓋回指定的冒險存檔進度
- `!saves`：查看當前伺服器所有歷史存檔
- `!note <線索>`：手動記錄冒險線索 ｜ `!journal`：查看冒險手記清單
- `!lore`：查看目前的世界觀設定集清單
- `!lore add 關鍵字 | 內容`：新增一筆世界觀專有名詞（AI 跑團時會自動調用）

### ⚙️ 系統管理 (!reset / !reload / !help)
- `!reset`：一鍵清除當前頻道的上下文記憶，重新開啟一個乾淨的新話題
- `!reload`：熱重載人設提示詞（改完 `general_prompt.txt` 後使用，免重開機）
- `!help`：在 Discord 彈出精美分類指令面板

## 🎨 如何自己修改機器人的個性與名字（自由客製化）

你想要讓機器人變成溫柔暖男、毒舌傲嬌、搞笑夥伴、還是忠實摯友？
**完全不需要改程式碼！只要改文字檔就可以！**

1. 打開本專案資料夾中的 **`general_prompt.txt`**（右鍵 -> 用「記事本」開啟）。
2. 你會看到裡面的文字說明。你可以直接修改裡面的設定，例如：
   - **想要更溫柔貼心**：把「微毒舌、冷幽默」改成「溫柔、體貼、像個善解人意的男友或摯友，總是用溫暖的口吻安慰對方」。
   - **想要叫特定名字**：在開頭寫上「你的名字叫阿星，平時喜歡用溫和的語氣說話」。
3. 按 `Ctrl + S` 儲存檔案。
4. **即時生效方法**：
   - 你不需要重開機器人，只要直接在 Discord 頻道發送指令：`!reload`
   - 機器人就會回覆「🔄 人設 prompt 已重新載入！」，新的個性立刻生效！

## ❓ 常見問題排錯指南 (FAQ)

### Q1：點擊 `2_一鍵安裝_Install.bat` 出現 `'python' 不是內部或外部命令`？
- **原因**：安裝 Python 時忘了勾選 `Add python.exe to PATH`。
- **解決方法**：重新打開剛才下載的 Python 安裝檔，選擇「Modify」或解除安裝後重新安裝，**務必記得勾選最下方的 `Add python.exe to PATH`**！

### Q2：機器人顯示綠燈在線上，但我在頻道傳訊息它完全不理我？
- **請檢查這兩點**：
  1. **Message Content Intent 有沒有開？** 回到 Discord Developer Portal -> Bot -> 檢查 **Message Content Intent** 是否確實開啟（藍色）並存檔。
  2. **頻道 ID 對不對？** 打開 `.env` 檢查 `TARGET_CHANNEL_ID` 是不是剛好就是你發話的那個文字頻道。

### Q3：啟動時跳出錯誤 `登入失敗！請確認 .env 中的 DISCORD_BOT_TOKEN 是否正確`？
- **原因**：Token 複製不完整，或者複製到了多餘的空格。
- **解決方法**：執行 `1_設定金鑰_Setup_Env.bat` 打開記事本，重新回到 Discord Developer Portal 點擊 Reset Token 複製，小心貼在 `DISCORD_BOT_TOKEN=` 後面並存檔。
