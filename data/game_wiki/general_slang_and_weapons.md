### 日常問候與回應
- **ㅎㅇ / 하이** `[ha i]`：嗨。
- **ㅇㅎ / 아하** `[a ha]`：啊哈。
- **ㅇㅇ / 응응** `[eung eung]`：嗯嗯。
- **안녕하세요** `[an nyeong ha se yo]`：你好 / 您好。
- **ㅂㅂ / ㅃ / 바이바이 / 빠이** `[ba i ba i / bba i]`：bye bye。
- **ㄱㄱ / ㄲ (고고)** `[go go]`：go go（叫人開始或走）。
- **시작** `[si jag]`：start 開始。
- **ㅅㄱ / 수고하다 / 수고하셨습니다** `[su go ha da]`：辛苦了（註：若為 `스겜` 的縮寫，則指遊戲內自殺速結束）。
- **ㅎㅇㅌ / 화이팅** `[hwa i ting]`：fighting 加油。
- **미안 / 미안해요 / 미안합니다** `[mi an hae yo]`：抱歉 / 對不起（較輕鬆的語氣）。
- **ㅈㅅ / 죄송 / 죄송해요 / 죄송합니다** `[joe song hae yo]`：不好意思 / 對不起（較正式客氣）。
- **ㄱㅊ / 괜찮아** `[gwaen chanh a]`：沒關係。
- **ㅋㅋ** `[k k]`：科科笑（類似 `w`）。
- **ㅎㅎ (하하)** `[ha ha]`：哈哈大笑。
- **ㅠㅠ / ㅜㅜ** `[yu yu / u u]`：嗚嗚哭。
- **ㄴㅇ (노우) / ㄴ / ㄴㄴ / 노** `[no u]`：no。
- **ㅇㄴ (아니 / 오노)** `[a ni / o no]`：不是 / oh no。
- **아니요** `[a ni yo]`：不是。
- **ㄱㅅ / ㄳ / 감사합니다** `[gam sa hab ni da]`：感謝 / 謝謝。
- **플레이** `[peul le i]`：play。
- **ㅇㅋ / 오케이** `[o ke i]`：ok。
- **가 / 가세요 / 가자** `[ga se yo]`：走 / 請走（不要留這）/ 走吧。
- **님** `[nim]`：稱呼他人的敬語（類似君 / 先生）。
- **ㅈㅁ (잠만 / 잠시만)** `[jam si man]`：稍等我一下。

- **뭐야** `[mwo ya]`：什麼？
- **~명** `[myeong]`：~名 / 幾個人。
- **야** `[ya]`：喂 / 欸（不太禮貌）。

- **ㄴㅇㅅ / 나이스** `[na i seu]`：nice。
- **ㄴㄱ / 누구** `[nu gu]`：誰。

### 遊戲內指責與貶義詞
- **응애** `[eung ae]`：嬰兒哭聲（拿來諷刺用）。
- **팀킬** `[tim kil]`：team kill 雷隊友。
- **ㅗ**：同中文「凸」，比中指。
- **ㅡㅡ**：無語、含生氣意思的表情。
- **잠수** `[jam su]`：潛水 / 掛機。
- **강퇴** `[gang toe]`：強退 / 踢出房間。
- **킵 / 칼킵 (칼같이 스킵)** `[kal gat i seu kip]`：像刀一樣迅速按 skip（當有人過場動畫很慢按跳過時會說）。
- **스겜 / ㅅㄱ (스피드 게임)** `[seu pi deu ge im]`：speed game，指**遊戲內自殺、馬上結束這局**。
- **렙차** `[leb cha]`：歧視低等玩家的人（**貶義**）。
- **렙충** `[leb chung]`：等級蟲，看重等級挑隊友的玩家（**貶義**）。
- **링남구 / 링여구** `[ling nam gu / ling yeo gu]`：常在公頻尋找有戒指伴侶的男 / 女玩家（**貶義**）。
- **물~** `[mul~]`：「水~」，指**慢慢農出來、不能反映真實實力的數值**（**貶義前綴**）：
  * **물량클 (물량 클랜)**：水貢獻量的公會（人多、靠少量天梯貢獻升排名，但實力多數不強，**貶義**）。
  * **물렙**：水出來的等級（等級高但技術差，**貶義**）。
  * **물엠 / 물엠블 / 물블럼**：水出來的成就（透過搭便車拿到難拿的成就，**貶義**）。
  * **물티어**：水出來的排位等級（排位高但技術不好，**貶義**）。
  * **물시즌**：水季（相對容易拿到排位的賽季）。
- **구걸러 / 구걸충** `[gu geol leo / gu geol chung]`：乞討者 / 乞討蟲（**貶義**）。
- **노공 / ~노공** `[no gong]`：不會攻略的人 / 拿某職業或某名字的人不會攻略（**貶義**）。
- **엠충 / 엠블충** `[em beul chung]`：成就蟲，對成就非常挑剔的玩家（**貶義**）。

### 遊戲內溝通通用語
- **~중** `[~jung]`：~進行中（例如：`자리중` = 座位保留中）。
- **자리 / ㅈㄹ** `[ja li]`：座位，指**有人已經預訂這個位置，請佔位的人自己離開**。
- **스킵** `[seu kip]`：skip 跳過過場動畫。
- **돌 / 돌진 / 돌격** `[dol jin / dol gyeog]`：突進 / 突擊 / 衝。
- **몰잡 (몰아서 잡겠다)** `[mol a seo jab gess da]`：**集怪＋清怪**。
- **어글 (어그리다)** `[eo geu li da]`：引怪（例如在 EP2 中，`ㄴㅇㄱ` = `노어글`，代表**不要引阿修羅**）。
- **스킬** `[seu kil]`：skill 技巧 / 技能。

- **ㄷㅎㅂ / 대화방** `[dae hwa bang]`：對話房 / 聊天房。

- **액술 (액션 술래잡기)** `[aeg syeon sul lae jab gi]`：**動感不抓**（貌似有只能持續做動感 30 秒的原則）。
- **삭전 / 삭**：炸彈模式用語。

### 活動與無限制模式（노리미트）用語
- **어패 / 어썸패스** `[eo sseom pae seu]`：awesome pass（活動的通行證任務，**寫在房名代表這房是在解通行證任務的房間**）。
- **팀킬전** `[tim kil jeon]`：team kill 戰，通常指**全員拿球棒、利用殭屍互相傷害**的房間。
- **아수라 죽이기** `[a su la jug i gi]`：專門打 EP2 第三關阿修羅的房間。
- **스킨직 (스킨 직업)** `[seu kin jig eob]`：**根據角色皮膚（造型）選擇對應武器**的房間。
- **올~** `[ol~]`：all~，全部人都拿指定的武器。

### 部落（클랜）與戰績統計用語

### 遊戲內廣場與聊天指令總表
- **/판사님 <問題>?**：在 `판사님` 與問號 `?` 之間輸入想問的事，法官會回答 `"응, 맞아"`（嗯，沒錯）或 `"응, 아니야"`（嗯，不是）其中之一（**句尾必須是問號**，有相關成就徽章）。
- **/신이시여 <問題>?**：在 `신이시여` 與問號 `?` 之間輸入想問的事，神會降下各種啟示（**句尾必須是問號**）。
- **/주사위**：以表情符號形式輸出 1~6 其中一個數字（**僅限廣場使用**）。
- **/윷놀이**：依韓國傳統擲柶遊戲實際機率，輸出 `뒷도` 到 `모` 的表情符號（**僅限廣場使用**）。
- **/노래방점수**：輸出卡拉 OK 分數 1~100 分其中之一。
- **/자판기**：販賣機，掉出各種飲料（有時也會什麼都沒掉出來）。
- **/해적룰렛**：海盜輪盤，出現 4 個空訊息、再試一次訊息或失敗訊息其中之一。
- **/동전던지기**：擲硬幣，以表情符號輸出各種硬幣結果（**僅限廣場使用**）。
- **/차단 <玩家暱稱>**：在後面輸入玩家暱稱並執行後，會將該玩家加入封鎖名單，**遮蔽該玩家的聊天訊息**（在遊戲對局中無法打開設定時非常好用；隊伍與部落聊天不適用）。
- **/차단해제 <玩家暱稱>**：解除封鎖該玩家，重新顯示其聊天訊息。
- **: (쌍점 기호 冒號)**：呼叫表情符號時使用，在聊天欄輸入 `:表情符號名稱` 即可不顯示文字、直接發送該表情符號。
