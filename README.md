# 🤖 Discord Gemini 隨性聊天的 AI 機器人 (Community Edition)

這是一個專門為了在 **Discord 伺服器中日常聊天陪伴**而設計的 AI 機器人！
內建自然生動的「隨性、微毒舌、冷幽默」群友個性，講話像一個真實生活在群裡的朋友，不說死板客服官腔，還看得懂圖片！

本專案專為**完全不會寫程式、沒有任何技術背景**的朋友打造。只需照著底下的教學點擊，約 10 分鐘就能讓自己的專屬 AI 機器人在 Discord 上線！

## 🌟 核心特色
- **💬 超自然日常聊天**：告別冷冰冰的客服罐頭訊息！像個真實群友一樣隨性閒聊、吐槽與陪伴。
- **🧠 記憶上下文連貫**：自動記住最近的聊天對話，不會說一句忘一句。
- **🖼️ 支援圖片解析**：把圖片丟進群裡，機器人能看懂圖片並跟你一起討論。
- **🎨 人設個性自由改**：不用改任何程式碼，用「記事本」修改文字檔就能自由切換性格（溫柔男友、微毒舌群友、搞笑搭子任你選）！
- **⚡ 超低門檻一鍵運行**：提供 Windows 專屬一鍵腳本，**不用開終端機輸入任何指令**！

## 🚀 零基礎超詳細安裝教學（跟著步驟點就對了！）

### 【第一步】申請 Discord 機器人（取得 Bot Token）

1. **進入 Discord 開發者中心**：
   - 使用瀏覽器打開 [Discord Developer Portal](https://discord.com/developers/applications) 並登入。
2. **建立機器人應用**：
   - 點擊右上角藍色按鈕 **「New Application」**。
   - 在 **NAME** 輸入你喜歡的機器人名字（例如：`阿吉` 或 `隨性群友`）。
   - 勾選同意服務條款，點擊右下角 **「Create」**。
3. **複製機器人身分證（Token）**：
   - 點擊左側選單的 **「Bot」**。
   - 找到中間的 **「Reset Token」** 按鈕點下去（若詢問點 Yes, do it!，若有雙重驗證請輸入驗證碼）。
   - 點擊 **「Copy」** 複製那一長串英數混雜的字串。
   > ⚠️ **【重要提醒】**：這串 Token 是機器人的專屬鑰匙，**千萬不要外洩給別人**！請先貼在記事本備用。
4. **🔥【極度重要！小白最容易漏掉的大魔王】開啟 Intents 權限**：
   - 在同一個「Bot」頁面往下滾動，找到 **Privileged Gateway Intents** 區塊。
   - **務必將以下三個開關全部點擊打開（變成藍色開關）**：
     - ✅ **Presence Intent**
     - ✅ **Server Members Intent**
     - ✅ **Message Content Intent**（🔥 沒開這個，機器人就無法看見群組訊息，會完全不理人！）
   - 打開後，點擊下方彈出的綠色按鈕 **「Save Changes」** 儲存！
5. **將機器人邀請進你的伺服器**：
   - 點擊左側選單的 **「OAuth2」** 裡面的 **「URL Generator」**。
   - 在 **SCOPES** 區塊中，只勾選：
     - ✅ `bot`
   - 下方會出現 **BOT PERMISSIONS** 區塊，請勾選以下權限：
     - ✅ Send Messages（發送訊息）
     - ✅ Send Messages in Threads（在討論串發送訊息）
     - ✅ Create Public Threads（建立公開討論串）
     - ✅ Embed Links（嵌入連結）
     - ✅ Attach Files（附加檔案）
     - ✅ Read Message History（讀取歷史訊息）
     - ✅ Add Reactions（新增反應）
   - 頁面最下方會產生一串 **GENERATED URL**，點擊右側的 **「Copy」**。
   - 在瀏覽器開新分頁貼上該網址，選擇你的 Discord 伺服器，點擊「授權」即可將機器人加進伺服器！

### 【第二步】取得免費 Google Gemini API Key

1. 打開瀏覽器前往 [Google AI Studio](https://aistudio.google.com/)。
2. 點擊登入你的 Google 帳號。
3. 進入後，點擊頁面上的 **「Get API key」** 按鈕。
4. 點擊 **「Create API key」**（若跳出選單，選擇 `Create key in new project` 即可）。
5. 複製產生的那一長串金鑰（開頭通常是 `AIzaSy...`），貼在記事本備用。
   > 💡 Google 提供非常充裕的每日免費對話額度，個人使用完全免費！

---

### 【第三步】複製 Discord 聊天頻道 ID

我們要告訴機器人該在哪個頻道陪大家聊天：

1. 打開電腦版 Discord。
2. 點擊左下角自己頭像旁的 **「使用者設定」（齒輪圖示）**。
3. 往下拉到左側選單的 **「進階」**（英文版為 Advanced）。
4. 將 **「開發者模式」**（Developer Mode）開關打開（變為綠色）。
5. 關閉設定，回到你的伺服器。
6. 對著**你想讓機器人聊天的文字頻道**點擊滑鼠右鍵，點選最下方的 **「複製頻道 ID」**。
7. 這是一串純數字，複製並貼在記事本備用。

---

### 【第四步】安裝 Python 執行環境

機器人需要 Python 環境才能在你的電腦上跑起來：

1. 前往 Python 官方下載頁面：[Python 官方下載](https://www.python.org/downloads/)。
2. 點擊黃色按鈕 **「Download Python 3.12.x」** 下載安裝檔。
3. 雙擊執行下載下來的安裝程式。
4. 🔥 **【最致命陷阱！請看清楚】**：
   - 在安裝程式的第一個畫面，最下方有兩個勾選框：
     - [ ] Use admin privileges when installing py.exe
     - [ ] **Add python.exe to PATH** 👈 **務必！一定要把這個打勾！**
   - **請務必把 `Add python.exe to PATH` 打勾**，再點擊上方的 **「Install Now」**！
   - 安裝完成後點擊「Close」關閉。

---

### 【第五步】下載專案與一鍵啟動（點 1、2、3 就好！）

1. **下載本專案**：
   - 在本 GitHub 頁面右上角，點擊綠色的 **`Code`** 按鈕，選擇 **「Download ZIP」**。
   - 下載後解壓縮到你喜歡的位置（例如電腦桌面）。
2. **依序雙擊三個小幫手**：
   - 🔹 **第 1 步：雙擊執行 `1_設定金鑰_Setup_Env.bat`**
     - 它會自動建立 `.env` 檔案並彈出「記事本」。
     - 請把剛才準備好的三串資料填入對應的位置（**等號後面不要留空格**）：
       ```env
       GEMINI_API_KEY=貼上你的Gemini_API_Key
       DISCORD_BOT_TOKEN=貼上你的Discord_Bot_Token
       TARGET_CHANNEL_ID=貼上你的純數字頻道ID
       ```
     - 按鍵盤 `Ctrl + S` 存檔，然後關閉記事本。
   - 🔹 **第 2 步：雙擊執行 `2_一鍵安裝_Install.bat`**
     - 黑色視窗會自動為你安裝需要的套件。
     - 請耐心等待 1~2 分鐘，看到「恭喜！所有環境與套件已安裝成功」後按任意鍵關閉。
   - 🔹 **第 3 步：雙擊執行 `3_一鍵啟動_Start_Bot.bat`**
     - 視窗會顯示正在啟動，最後顯示：
       ```
       🚀 [你的機器人名字] 已成功連線至 Discord！
       ```
     - 回到 Discord，你會看見機器人亮起綠燈上線了！
     - 在聊天頻道直接打字（例如：`今天好累喔`），它就會用語氣自然的風格回應你囉！
   > 💡 **小撇步**：保持黑色視窗開著，機器人就會一直在線上；想關閉機器人時，直接關閉該視窗即可。

## 🎨 如何自己修改機器人的個性與名字（自由客製化）

你想要讓機器人變成溫柔暖男、毒舌傲嬌、還是搞笑夥伴？
**完全不需要改程式碼！只要改文字檔就可以！**

1. 打開本專案資料夾中的 **`prompt.txt`**（右鍵 -> 用「記事本」開啟）。
2. 你會看到裡面的文字說明。你可以直接修改裡面的設定，例如：
   - 想要更溫柔貼心：把「微毒舌、厭世」改成「溫柔、體貼、像個善解人意的男友或摯友，總是用溫暖的口吻安慰對方」。
   - 想要叫特定名字：在開頭寫上「你的名字叫阿星，平時喜歡用溫和的語氣說話」。
3. 按 `Ctrl + S` 儲存檔案。
4. **即時生效方法**：
   - 你不需要重開機器人，只要直接在 Discord 頻道發送指令：`!reload`
   - 機器人就會回覆「🔄 人設 prompt.txt 已重新載入！」，新的個性立刻生效！

## ❓ 常見問題排錯指南 (FAQ)

### Q1：點擊 `2_一鍵安裝_Install.bat` 出現 `'python' 不是內部或外部命令`？
- **原因**：安裝 Python 時忘了勾選 `Add python.exe to PATH`。
- **解決方法**：重新打開 Python 安裝檔，選擇「Modify」或解除安裝後重新安裝，**務必記得勾選最下方的 `Add python.exe to PATH`**！

### Q2：機器人顯示綠燈在線上，但我在頻道傳訊息它完全不理我？
- **請檢查這兩點**：
  1. **Message Content Intent 有沒有開？** 回到 Discord Developer Portal -> Bot -> 檢查 **Message Content Intent** 是否確實開啟（藍色）並存檔。
  2. **頻道 ID 對不對？** 打開 `.env` 檢查 `TARGET_CHANNEL_ID` 是不是剛好就是你發話的那個文字頻道。

### Q3：啟動時跳出錯誤 `登入失敗！請確認 .env 中的 DISCORD_BOT_TOKEN 是否正確`？
- **原因**：Token 複製不完整，或者複製到了多餘的空格。
- **解決方法**：執行 `1_設定金鑰_Setup_Env.bat` 打開記事本，重新回到 Discord Developer Portal 點擊 Reset Token 複製，小心貼在 `DISCORD_BOT_TOKEN=` 後面並存檔。
